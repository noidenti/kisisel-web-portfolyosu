# Kişisel Web Portfolyosu

Bilgisayar Programcılığı bölümü projem kapsamında, modern tasarım ilkelerine sadık kalarak geliştirdiğim web portfolyosudur. Bu projede web geliştirmenin temellerini ve tasarım dinamiklerini pratik etme şansı buldum.

### Kullanılan Teknolojiler
- HTML5
- CSS3

### Proje Detayları
- Sayfa iskeleti oluşturma ve biçimlendirme pratikleri yapıldı.
- Temel arayüz tasarımı mantığı uygulandı.
